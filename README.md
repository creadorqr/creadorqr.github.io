# QR Creator

App web simple para crear códigos QR: pegás un link y aparece el QR al instante.

- Descargar el QR como PNG
- Compartirlo (en el celular)
- Funciona sin conexión y se puede instalar en Android como app (PWA)

## Uso

Abrí `index.html` en el navegador, o activá GitHub Pages en el repo
(Settings → Pages → rama `main`, carpeta `/root`) y entrá desde el celular.
En Chrome para Android: menú ⋮ → "Agregar a pantalla principal".

Librería QR: [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT).
